# Privacy contract

Curiosity Lab is intentionally local-first.

## Runtime behaviour

- No analytics, telemetry, advertising or tracking pixels.
- No accounts, authentication or user profiles.
- No calls to external APIs or third-party assets.
- No cookies.
- No collection of names, locations, device identifiers or other personal information.
- Images created with **Save image** stay on the device unless the user chooses to move or share them.
- The service worker only caches this application's own static files for offline use.

## Repository rule

Do not add personal information, secrets, private URLs or identifying sample data to this repository. Use fictional or generic examples only.
