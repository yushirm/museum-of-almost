# 084 — COMMONS / NOW — The World Between Samples

- **Ancestor:** `31c89122501e44038f03efc639e1142bb66959f4`
- **Target room:** COMMONS / NOW
- **Room density classification:** CROWDED
- **Generation mode:** DEEPEN
- **Selection pressure:** Make the existing shared planetary snapshot more honest about what sparse spatial and temporal sampling can miss without adding another feed, top-level instrument, control, or polling cycle.
- **Retained trait:** One latched, non-personal planetary instrument using fixed coordinates, manual reacquisition, explicit source boundaries, no visitor location, no tracking, and no stored visitor history.
- **Growth introduced:** A **Sampling Floor / What Can Fall Between Samples?** layer inside the existing Reduction Register, borrowing from sampling theory to distinguish measured stations from the unsampled field between them, a single latch from an observed trend, and rolling/open-set count changes from instantaneous physical change.
- **Merged / reframed / pruned:** Sampling-limit semantics were merged into the existing collapsed Reduction Register. Nothing was pruned; acquisition, network boundaries, persistence, and downstream calculations were unchanged.
- **Net visitor-facing surface change:** SAME — the default page gains no new top-level or collapsed row; the existing Reduction Register becomes deeper only when opened.
- **Pattern intentionally avoided:** Another dashboard widget or public-data feed, automatic polling, pseudo-global extrema, fake trend reconstruction, invented uncertainty bars, or a false Nyquist/anti-aliasing threshold unsupported by the source cadences.
- **Future evolutionary headroom created:** Sampling design, observation cadence, spatial resolution, representativeness, missed transients, and the difference between measurement support and reconstruction can now evolve through one explicit sampling vocabulary.
- **Resulting fitness:** Higher scientific integrity and stronger unity. COMMONS now distinguishes when and where its feeds mean something, what survives reduction, and what an honest sample may still leave unseen.
