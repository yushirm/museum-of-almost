# 140 — COMMONS / NOW — One Latch Becomes a Weave

- **Ancestor:** `3a526b36bd053acee0c7e7804cba51a985c12053`
- **Target room:** COMMONS / NOW
- **Room density classification:** CROWDED

- **Selection pressure:** Commons already carries a dense stack of current-feed headlines, Sample-and-Hold provenance, a thirteen-point world map, Longitude Clock, State Space, Difference Engine, planetary section/field sheet, signal panels and explicit source boundaries. Its dominant interaction/visual families are fixed-station selection, linked views, comparative scales, sparse map geometry, printable measurement sheets and state propagation; its explanatory families repeatedly stress fixed coordinates, one-latch semantics, missing-data honesty and no interpolation/history. The last three successful Commons generations used coordinate guides, linked map-to-clock selection and selected-light exposure. The immediately previous two were both SAME-surface, so novelty debt was recomputed as ACTIVE. Four materially different candidates were compared: **EXPANSION**, another standalone current-data instrument; **RELATIONAL DEEPENING**, propagating selection into another existing view; **STRUCTURAL HEADROOM**, consolidating the dense measurement stack; and **WILD CROSSOVER**, translating the existing thirteen-point latch into textile notation. The textile crossover won because it adds a memorable new representation and visitor-facing surface while staying inside the same fixed data boundary and changing axis away from another linked-view-only generation.
- **Retained trait:** one shared non-personal planetary instrument; thirteen fixed coordinates; one current latched weather sample; local solar light geometry; exact station values remain authoritative; missing values remain missing; no visitor location, visitor text, analytics, tracking, persistence, automatic polling, new public service, remote asset, interpolation, trend, forecast or historical replay.
- **Growth introduced:** a new **WEATHER LOOM / ONE LATCH, THIRTEEN THREADS** surface orders the existing fixed stations west to east and renders four woven bands per station: temperature, wind and precipitation as marks normalized only within the finite values of the current thirteen-point latch, plus categorical day/twilight/night light state. Each thread has an exact semantic label containing its station measurements, and selecting a thread selects the same existing fixed world window. Missing quantitative values render as visibly unwoven rather than substituted. The surface explicitly states that the weave is comparative notation, not a continuous weather field or calibrated physical cloth.
- **Evolutionary axis used:** expressive representation / textile-notation crossover / one-latch comparative encoding / fixed-station interaction.
- **Merged / reframed / pruned:** no existing Commons surface, feed, station, lens, control, field sheet, data contract or provenance boundary was removed. The generation adds one compact top-level representation using the already-loaded `commons-solar-dial.js` and `commons-solar-dial.css` assets; no new runtime asset or service-worker entry was required.
- **Net visitor-facing surface change:** UP — one new compact top-level weather-loom region with thirteen selectable threads and four derived bands per thread.
- **Pattern intentionally avoided:** another methodology drawer, caveat, ledger, register, dashboard card, historical graph, polling loop, new provider, visitor location, free-text input, inferred continuous weather surface, animation, another pure linked-view highlight, or a second planetary map.
- **Recent-pattern repetition avoided:** yes — generations 119 and 134 both changed existing surfaces without increasing visitor-facing surface, and both relied heavily on selection/state propagation. This generation changes representational discipline to textile notation and earns visible new surface rather than merely making another existing panel answer selection.
- **Future evolutionary headroom:** the loom creates a reusable expressive boundary for future Commons work: later generations can transform the same held snapshot into other non-interpolating cultural or scientific forms, or make the loom participate in an earned cross-surface relationship, without adding feeds or pretending sparse samples form a world model. Because the exact numerical readouts remain elsewhere, the expressive layer can evolve without becoming the data authority.
- **Novelty-debt status after this generation:** REPAID / CLEAR — the two previous successful Commons generations were SAME-surface; this generation deliberately spends that debt on visible UP-surface experiential growth and a new expressive discipline.
- **Resulting fitness:** higher. Commons can now be read not only as a map, clock, comparison console and field section but as one held planetary textile: thirteen discontinuous threads share a moment without the interface inventing weather between them.
