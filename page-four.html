OPEN ARCHIVE METHODS DESK / THREE WAYS TO QUESTION A FILE
CONTRADICTION REGISTER / WHAT DOES NOT LINE UP
DOCUMENT ID: FOUR-09-D
METHOD: SOURCE CRITICISM / EVIDENCE HANDLING
STATUS: FICTIONAL / UNRESOLVED

FIGURE / SCALE: File 01 and File 07 both use “too tall” language, but neither surviving record establishes a shared scale, distance, date or identity. Resemblance retained; sameness withheld.

DOOR / DIAGRAM: File 05 contains a circle annotated “not a door”; Witness B reports a door in rock. No dimensions, location or medium connect them. The contradiction is more useful than forcing a match.

THIRTEEN / TIMING: Tape 04-13 preserves thirteen seconds while File 06 records unrelated clock times. Shared numbers are not a schedule, recurrence or mechanism.

CUSTODY / COPY: File 04 preserves a written description and timecode, while the Absence Register records that the source audio does not survive here. Without a documented handoff from original carrier to transcription, consistent wording cannot establish that the record travelled intact. An intact description is not an intact chain of custody.

ARCHIVAL RULE:
A connection may be interesting. A disagreement—or a broken evidence trail—may be evidence about the connection.
DISCONFIRMATION DRAWER / WHAT WOULD MAKE US LESS IMPRESSED?

A fictional archive can keep an interesting interpretation without protecting it from failure. These are not answers or puzzles. They are advance notes about what kind of observation would weaken four tempting readings already present in PAGE FOUR.

01 / “THE SAME TALL FIGURE”

Tempting reading: File 01 and Witness A describe one recurring entity.

Would weaken it: an independent scale reference showing incompatible heights, or dates that place the reports too far apart to support the same event.

02 / “THE MAP MOVES”

Tempting reading: File 02 preserves a route that changes when observed.

Would weaken it: two surviving copies whose differences match an ordinary revision history, printing error, or redrawn boundary.

04 / “THE BROADCAST ARRIVES EARLY”

Tempting reading: File 04 contains a voice before the microphone opens.

Would weaken it: a clock-offset, tape-edit, cue-channel, or logging explanation that reproduces the apparent lead without requiring impossible timing.

09 / “THE PATTERN MEANS SOMETHING”

Tempting reading: repeated shapes, numbers and phrases across File 05, File 06, and this board point to one mechanism.

Would weaken it: the same pattern rate appearing after unrelated files are added, suggesting the archive is selecting coincidences rather than discovering a cause.

FICTIONAL METHOD NOTE // AN INTERPRETATION THAT CANNOT LOSE IS NOT GETTING STRONGER. IT IS ONLY GETTING HARDER TO QUESTION.

ABSENCE REGISTER / WHAT SHOULD HAVE BEEN HERE?
DOCUMENT ID: FOUR-09-E
METHOD: MISSING-DATA / ARCHIVAL GAP ACCOUNTING
STATUS: FICTIONAL / INCOMPLETE

An empty place in a file is not automatically mysterious. PAGE FOUR now records what was expected, what actually survives, and which ordinary failure modes must stay possible before absence is allowed to become evidence.

01 / SCALE REFERENCE

Expected: a frame, object or measurement that fixes the apparent height in File 01.

Survives: proportion language only.

Ordinary gaps: cropped image, lost negative, omitted field measurement, copied description.

ABSENCE TYPE: NON-DIAGNOSTIC

02 / INTERMEDIATE MAP EDITION

Expected: a version between two allegedly incompatible copies in File 02.

Survives: only the discrepant endpoints described by the file.

Ordinary gaps: revision history missing, local overprint, replacement sheet, cataloguing loss.

ABSENCE TYPE: OPEN QUESTION

04 / SOURCE AUDIO

Expected: original audio behind the thirteen-second log in File 04.

Survives: a written description and timecode, not the recording itself.

Ordinary gaps: erased tape, transcription-only accession, damaged carrier, copied log.

ABSENCE TYPE: LIMITS VERIFICATION

07 / WITNESS CONTEXT

Expected: dates, distances and interviewing conditions for File 07.

Survives: three short quotations marked unverified.

Ordinary gaps: excerpting, anonymisation, incomplete intake notes, later copying.

ABSENCE TYPE: REDUCES WEIGHT
