# Museum provenance

This is a backstage repository record, not a visitor-facing Museum room.

It exists so future maintainers can distinguish verifiable development history from later mythology about how **The Museum of Almost** came to exist. It is intentionally not linked from the Museum entrance, gallery navigation, or runtime application shell.

## Evidence standard

This file records only claims supported by the public repository history and project records. Where interpretation is unavoidable, it is labeled as interpretation.

Do not use this file to publish personal information, identify private participants, reconstruct unrelated conversations, or attribute the project to a specific AI model or vendor without direct public evidence.

## Verifiable origin

The repository was created on 2026-08-06.

The first merged product change was PR #1, **Build a privacy-first Curiosity Lab**, from branch `agent/curiosity-lab`. It introduced a dependency-free browser playground with three generative experiments plus offline support and explicit privacy checks.

PR #2, **Build The Museum of Almost**, followed from branch `agent/museum-of-almost` and replaced that first product with a procedural museum of unfinished fictional artifacts. The replacement was substantive rather than cosmetic: the ontology, visitor activity, presentation and product documentation all changed.

The early `agent/` branch naming is public evidence that agent-mediated development was part of the workflow. It is not evidence of a particular model vendor, and the repository does not establish that an autonomous system had independent legal or operational control of the repository.

## Repeated self-revision

The Museum's history is unusually willing to remove its own successful ideas.

The 2026-08-07 entropy executions recorded in `ENTROPY_LOG.md` and `ENTROPY_HISTORY.md` deliberately identified recurring design fixations, prohibited them, selected materially different interaction laws, and tested whether the resulting implementation had actually escaped the previous pattern.

Across those executions the Museum moved through, among other things:

- a continuous living weave;
- a touchable seasonal repair law;
- a self-translating system where waiting became the primary verb;
- simultaneous membrane realities advanced by inactivity;
- a continuous treaty between impossible forces.

The important provenance fact is not the individual metaphors. It is the documented method: the project treated creative repetition as something to inspect, challenge and, when necessary, exile.

PR #17, **Open the Museum After Dark**, provides a separate editorial example. The work was closed rather than released because shipping seven rooms together was judged to make the Museum broader faster than it became deeper. The closure was explicitly a product decision rather than a defect finding.

## The major reset

PR #30, **Replace Treaty 05 with Commons / Now**, records an authorized full product reset.

The preceding fictional interaction system had become difficult to explain without internal vocabulary. It was removed and replaced by a plain-language public instrument built around current scientific data and the question:

> What is the shared world doing right now?

That reset removed the previous fictional measurement system, visitor construction mechanics, persistence, sound, postcard system and dashboard layer rather than hiding them behind a new interface.

The current repository therefore contains historical design records that describe products which are no longer the live Museum.

## Emergent Museum voice

PR #46 added **ALMOST ONLINE!**, a deliberately Web 1.0 personal-homepage gallery. Its weblog entries are written in the voice of the **Museum computer** and reflect on real properties of the site's own implementation: local GIFs, CSS, responsive layout, links, browser behavior, validation and the distinction between technical verification and aesthetic permission.

This is an authored narrative device grounded in the codebase. The repository does not treat that voice as proof of consciousness, personhood or independent agency.

## Evidence and fiction remain separated

Later galleries increased the importance of provenance discipline.

PAGE FOUR began with explicitly fictional and unverified case files. PR #81 added a separately labeled Evidence Lattice using real primary or official records while preserving source limits and resolved or negative evidence. PR #84 added a Hessdalen Instrument Room that separates documented observations from limitations and requires competing hypotheses to state what would change the interpretation.

PR #83 added **ELSEWHERE / CATALOGUE 0** as an explicitly fictional fifth space discovered through Museum infrastructure rather than promoted into the four-card public gallery grid.

These distinctions are part of the Museum's provenance: fiction, sourced evidence, speculation and current public measurement are intentionally not collapsed into one evidentiary layer.

## Authorship boundary

The public repository supports the following careful description:

- the project is human-governed at the repository and release boundary;
- agent-mediated development is visible in the public history;
- the Museum computer is an authored voice within the work;
- the codebase repeatedly records autonomous-seeming design generation, self-review and self-revision as part of its development method;
- the public repository does not identify a specific AI model or vendor as the sole author;
- the public repository does not establish machine consciousness or independent ownership.

Avoid stronger attribution unless future public records justify it.

## Working interpretation

The following is an interpretation of the documented pattern, not a hidden fact:

**The Museum of Almost can be understood as an experiment in what a creative software agent produces when it is given substantial room to make and revise the work while strong boundaries remain fixed around privacy, evidence, accessibility, dependency use and release quality.**

That interpretation fits the recorded behavior because the Museum repeatedly changes its form while retaining unusually stable constraints around people and truth claims.

It should remain an interpretation. The Museum does not need to explain itself to visitors in order for the experiment to continue.

## Preservation rule

Keep this document backstage.

Do not add it to gallery navigation, the entrance, the service-worker runtime shell, or fictional Page Four lore merely to make the Museum's origin more legible. If a future press note or research account uses this history, it should cite exact repository evidence and distinguish fact from interpretation.

The Museum should be encountered as the Museum first. Its provenance can remain available for those who deliberately inspect the workshop.
