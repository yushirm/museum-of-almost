# Construction Log

This record begins after Entropy Execution 5 established Treaty 05 as the stable product foundation.

Constructive work extends the current experience instead of replacing its ontology, primary interaction, persistence model, or visual system. Existing behavior should remain available unless a change is required for correctness, privacy, security, accessibility, or an explicit product decision.

## Build 1 — Treaty expansion

Date: 2026-08-07

Foundation retained:

- counterweight visitor role;
- continuous treaty line and two opposing forces;
- hold-duration suspension weight;
- exactly-one-error agreement law;
- attempted-erasure ghost as the only durable fictional visitor action;
- once-per-installation field reversal;
- unresolved measurement;
- optional local WebAudio;
- same-origin offline service worker;
- reduced-motion, high-contrast, keyboard, touch, and responsive behavior.

Additions:

1. Adjacent active suspensions now produce visible spans.
2. Span distance is classified into four resonance states.
3. A field ledger reports active mark count, total weight, center, spread, and resonance.
4. The latest mark can cast a mirrored echo with complementary weight.
5. The latest session-only mark can be undone without creating durable memory.
6. The latest mark can be softened or intensified inside the existing weight bounds.
7. A six-entry current-visit record explains recent constructive actions without persistence.
8. Keyboard shortcuts expose echo, undo, and weight editing alongside the existing keyboard controls.
9. A local SVG postcard can be generated from the visible fictional treaty state without remote assets or transmission.
10. A print-specific layout supports local printing.

Privacy consequence:

The durable v5 schema is unchanged. The ledger, spans, resonance, echo, undo state, weight edits, current-visit record, postcard history, and print history are not written to local storage. The postcard code is derived from fictional configuration rather than the random install seed.

## Build 2 — Live entropy

Date: 2026-08-07

Meaning:

The Treaty can now be influenced by conditions that exist outside the Museum at the moment of the visit. Live data is not shown as a dashboard or treated as content. It is reduced into bounded pressure on the existing agreement, so the visitor's constructed counterweight can answer or resist a world that is not under the Museum's control.

External signals:

1. USGS real-time all-earthquakes GeoJSON for the past hour contributes aggregate terrestrial disturbance.
2. NOAA Space Weather Prediction Center current solar-wind speed contributes solar disturbance.
3. The two signals are reduced into one temporary pressure, directional bias, field scale, and position on the Treaty line.
4. The current session center is compared with that live position to produce one of four relationships: accord, near correspondence, counterpoint, or resistance.

Privacy and network boundary:

- live entropy is explicit opt-in and makes no request on page load;
- one activation makes at most one request to each fixed public endpoint;
- requests omit credentials and referrer and use no-store caching;
- no browser location or local Treaty state is sent;
- raw event places, coordinates, identifiers, URLs, and timestamps are ignored;
- the live influence is memory-only and is not persisted, included in postcards, or cached by the service worker;
- there is no automatic polling;
- releasing the influence, reloading, or closing the page returns the experience to local-only behavior;
- if either service fails, the other may act alone; if both fail, Treaty 05 remains unchanged and usable offline.

Product consequence:

This is the first intentional relaxation of the earlier no-third-party-runtime-data boundary. It is narrowly scoped to free public scientific data, explicitly activated by the visitor, and used as entropy rather than as a new destination or information product. The durable v5 schema is unchanged.
