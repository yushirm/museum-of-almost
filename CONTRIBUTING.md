# Contributing

The Museum of Almost is publicly viewable but is not an open-source or community-maintained project.

External contributions are not accepted unless the repository owner explicitly invites them. Please do not open unsolicited pull requests, issues, discussions, or requests for access.

Repository changes are made only by the owner or by automation and AI tools acting with the owner's explicit authorisation. Authorised work should use a dedicated branch, pass the repository checks, and be merged deliberately through a pull request.

Never add personal information about any person, credentials, private correspondence, private URLs, real contact details, or identifying sample data. Use fictional and generic material only.

Forks are separate copies and are not endorsed, maintained, or supported by this repository.
