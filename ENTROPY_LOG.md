### Mutation thesis

The Museum of Almost is now a translation system for non-linguistic conditions. It does not ask the visitor to choose an object, position, correction, destination, or score. The visitor is an accomplice because allowing a measure to complete is a meaningful act; touching the broad surface after the effect appears is optional interference. The same weave is reused every time, but its semantic source changes. Rhythm determines when agency exists. A successful measure never resolves ambiguity: it creates exactly one new contradiction, replacing the previous durable contradiction. The previous timeline could not express this concept without preserving target selection, ordered slots, scalar error, and correction as ontology, so those structures were removed rather than renamed.

2. Remembered action is inverted: actions are forgotten, while one contradiction produced by them survives.
3. Inactivity-driven correction is inverted: inactivity is no longer an automatic repair force; waiting is the visitor's primary contribution.
