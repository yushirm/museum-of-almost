### Adversarial self-review so far

The returning timeline topology was treated as a likely regression to Execution 2. The implementation was rejected unless it could remain coherent with every named position, correction target, season, scalar misregistration, and ordered term removed. The final topology is continuous and analog; the only discrete marks are temporary visitor suspensions, not destinations or predefined timeline terms.

A privacy risk existed because hold duration and pointer position are central mechanics. Both are intentionally confined to transient session memory. Persistent sanitisation strips duration, pointer paths, timestamps, visit counters, geometry, action history, and semantic labels. Only the erased mark's bounded position and weight may survive.

A mobile interaction risk was addressed by preserving `touch-action: pan-y` and avoiding `preventDefault()` on pointer gestures. Vertical page scrolling remains available; pointer cancellation cleanly abandons an in-progress suspension.

The severe constraint is enforced by rendering from shared state: a suspension changes visible marks, both force scales, field scale, treaty status, measurement, and action availability; erasure changes active marks, ghost memory, measurement, status, and potentially the one-time reversal. Cursor movement changes both the counterweight and magnetic-field origin. Sound-toggle changes its control and live status. No meaningful state transition is represented by a single isolated visual change.

### Anti-convergence result

The implementation has no membrane sections, triplicate peer realities, directional north/east/south/west action model, persisted geometry tuple, silent generation counter, semantic relabeling engine, late-warning mechanic, z-order folding, or inactivity timer. It also has no room navigation, collection system, node field, correction slots, translation pair, score, unlocks, or progress model. The new organising state is a continuous counterweight plus ephemeral suspension errors; only attempted erasure may persist.

### Primary-fixation failure test

This cannot reasonably be described as another parallel membrane field. There are no layers to separate, no geometry tuple to preserve, no generated reality labels, and no inactivity-driven generation. It also cannot reasonably be described as Execution 2's ordered correction timeline because there are no predefined positions, named terms, cursor-selected repair targets, seasons, or scalar misregistration values. The site is best described as a continuous treaty between opposing forces whose temporary order depends on suspension and deliberate error.
