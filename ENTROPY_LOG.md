They are reconciled as one organism made from three translucent membrane-realities. The system mistakes the visitor for an internal boundary, so visitor input can only separate layers; it offers no merge command. Drag direction or keyboard direction changes geometry immediately but leaves the internal generation untouched. After a quiet interval, and only then, the organism advances one generation, partially re-folds itself, changes the semantic labels attached to the preserved geometry, reveals more annotation, and reports the warning after the reinterpretation has already happened. Silence therefore creates information while activity creates spatial separation.

### Adversarial self-review so far

A mobile scroll trap was identified during implementation because the first draft used `touch-action: none` across a large full-width interaction field. It was changed to `touch-action: pan-y`, preserving ordinary vertical page movement while retaining tap, keyboard, mouse-drag, and horizontal-touch separation.

A second risk was continuous timer-driven mutation, which would have recreated the previous timed pulse and could repeatedly update live text without new visitor intent. The implemented idle law advances at most one generation per quiet interval and stops until a later visitor interaction or return schedules another interval.
